Foundation

Theming

Semantic colour roles, light and dark palettes, accents and translucent tokens.
Your state. Rust callbacks.

The examples below come from the native Catalog. Preview images are rendered by the toolkit, not recreated in HTML. They do not demonstrate native input or desktop blur.

Semantic roles

01 / 04

Components draw with roles, not literal colours, so one palette restyles everything.

How to use Rust source
Rust declarationSource
text("Saved").color(ColorToken::Success)
panel![...].background(ColorToken::Base200).border_color(ColorToken::Border)

Catalog excerpt: names such as app, callbacks and helper functions belong to the example. View the complete source or start with the runnable app guide.

Accent and mode

02 / 04

Try a colour and a mode; this whole site re-themes live.

How to use Rust source
Rust declarationSource
fn theme(app: &App, system: ThemeMode) -> UiTheme {
    let base = if app.dark { Palette::dark() } else { Palette::light() };
    UiTheme::from_palette(base.with_accent([0.15, 0.39, 0.92, 1.]))
}
native::run_ui_with_theme(options, app, view, theme)?;

Window surfaces

04 / 04

The preview shows surface alpha, not desktop blur. Native GPU windows can request transparency/OS blur; text stays opaque. Software falls back to opaque.

How to use Rust source
Rust declarationSource
cargo run --release --features native-gpu --example catalog -- \
    --page theming --theme dark --background blur --window-opacity 0.86
# --background transparent: alpha without a blur request
# --background opaque: solid window; software fallback
# blur/material: public AppKit material; compositor: opt-in private macOS blur.

API reference

Properties and behavior documented by this Catalog page.

APIBehavior
ColorToken::alpha(percent)A role at 0..=100% opacity, e.g. "@primary/15".
Palette::with_accent(rgba)Set primary/accent and pick contrasting foregrounds.
UiTheme::from_palette(palette)Build a theme from a fully custom palette.
run_ui_with_theme(options, state, view, theme)Derive the theme from application state.
Catalog: --background / --window-opacityIndependent background opacity and tint; foreground stays opaque. Select Material or Compositor in the sidebar.
