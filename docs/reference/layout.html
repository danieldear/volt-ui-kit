API reference

Properties and behavior documented by this Catalog page.

APIBehavior
vstack! / hstack! / zstack! / stack!Vertical, horizontal, layered and responsive stacks.
.gap(value, Axis)Space between children on one or both axes.
.padding(value, Edge)Inner space on any combination of edges.
.flow(Flow)Place content: corners, edges or centre.
.align(Align)Cross-axis alignment, including Stretch.
spacer()Flexible space that pushes siblings apart.
responsive(v).at(Breakpoint, v)A value that changes with window width.
