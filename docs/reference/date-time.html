Date & time

Calendars, date and range pickers, and a time picker.
Your state. Rust callbacks.

The examples below come from the native Catalog. Preview images are rendered by the toolkit, not recreated in HTML. They do not demonstrate native input or desktop blur.

Calendar

01 / 04

A month grid with keyboard-reachable days, today marker and paging.

How to use Rust source
Rust declarationSource
calendar(year, month)
    .key("cal")
    .selected(app.date)
    .on_select(|app: &mut App, d| app.date = Some(d))
    .on_month_change(|app: &mut App, y, m| app.month = (y, m))

Catalog excerpt: names such as app, callbacks and helper functions belong to the example. View the complete source or start with the runnable app guide.

Date picker

02 / 04

A field that opens a calendar popover.

How to use Rust source
Rust declarationSource
date_picker(app.date, &app.picker)
    .key("due")
    .state(|app: &mut App| &mut app.picker)
    .on_change(|app: &mut App, d| app.date = Some(d))

Catalog excerpt: names such as app, callbacks and helper functions belong to the example. View the complete source or start with the runnable app guide.

Date range

03 / 04

Two months side by side; the first click sets the start.

How to use Rust source
Rust declarationSource
date_range_picker(app.range, &app.range_picker)
    .key("trip")
    .state(|app: &mut App| &mut app.range_picker)
    .on_change(|app: &mut App, r| app.range = r)

Time picker

04 / 04

Hour and minute steppers with an optional AM/PM switch.

How to use Rust source
Rust declarationSource
time_picker(app.time).key("alarm").twelve_hour(true).minute_step(5)

Catalog excerpt: names such as app, callbacks and helper functions belong to the example. View the complete source or start with the runnable app guide.

Try it in the native Catalog

From the repository root. Static snapshots cannot demonstrate editing, keyboard focus, scrolling or animation.

TerminalSource

    --features native-gpu,native-desktop \
    --example catalog -- --page date-time
