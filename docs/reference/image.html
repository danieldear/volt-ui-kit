Image

Image backgrounds with fit, position, opacity and clipping.
Your state. Rust callbacks.

The previews below run the original Catalog declarations and Rust callbacks in WebAssembly. Native-only OS services are identified explicitly; this is not a simulation of desktop permissions or blur.

Fit

01 / 05

Cover, contain or tile any decoded image.

How to use Rust source
Rust declarationSource
vstack![].background_image(image.clone().background().fit(ImageFit::Cover))

Catalog excerpt: names such as app, callbacks and helper functions belong to the example. View the complete source or start with the runnable app guide.

Cutouts with clear edges

03 / 05

Reusable alpha-coverage union, intersection, subtraction and exclusion. These compose masks; they do not generate boolean vector-path geometry.

How to use Rust source
Rust declarationSource
photo.mask(mask_union([left_mask(), right_mask()]), MaskMode::Alpha);
photo.mask(mask_difference(left_mask(), right_mask()), MaskMode::Alpha);
// Also: mask_intersection(a, b), mask_exclude(a, b).

Catalog excerpt: names such as app, callbacks and helper functions belong to the example. View the complete source or start with the runnable app guide.

A softer edge

04 / 05

Gradient alpha masks blend an image into its surface without a pre-rendered asset.

How to use Rust source
Rust declarationSource
photo.mask(mask.background_gradient(Gradient::linear(90., [
    (0., "#FFFFFF00"), (0.25, "#FFFFFFFF"),
    (0.75, "#FFFFFFFF"), (1., "#FFFFFF00"),
])), MaskMode::Alpha)

Catalog excerpt: names such as app, callbacks and helper functions belong to the example. View the complete source or start with the runnable app guide.

Overlays that belong to the image

05 / 05

Normal, multiply, screen, overlay, color burn and difference run on both GPU and software. Isolation keeps compositing inside this preview.

How to use Rust source
Rust declarationSource
zstack![photo, tint.blend_mode(BlendMode::ColorBurn)]
    .isolate(true).clip_contents(true);
// BlendMode::Difference is colour difference, not alpha subtraction.

Catalog excerpt: names such as app, callbacks and helper functions belong to the example. View the complete source or start with the runnable app guide.

Try it in the native Catalog

From the repository root. The browser previews cover shared components; run the native Catalog for OS integrations and native platform acceptance.

TerminalSource
cargo run --release --locked \
    --features native-gpu,native-desktop \
    --example catalog -- --page image
