Background tasks

Worker threads report progress through a bounded message queue.
Your state. Rust callbacks.

The examples below come from the native Catalog. Preview images are rendered by the toolkit, not recreated in HTML. They do not demonstrate native input or desktop blur.

Worker progress

01 / 01

A thread sends progress; the UI applies it on its own thread and ignores stale results.

How to use Rust source
Rust declarationSource
// Worker thread
sender.send(Message::Progress { generation, step })?;

// UI thread, batched per event-loop turn
fn update(app: &mut App, message: Message) {
    let Message::Progress { generation, step } = message;
    if generation == app.generation { app.progress = step; }
}

native::run_ui_with_messages_and_theme(options, app, view, theme,
    |app, sender| app.sender = Some(sender), update)?;

Catalog excerpt: names such as app, callbacks and helper functions belong to the example. View the complete source or start with the runnable app guide.
