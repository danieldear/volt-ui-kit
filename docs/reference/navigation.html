Navigation

Destination lists in sidebar, rail or bottom placement, and the app shell around them.
Your state. Rust callbacks.

The examples below come from the native Catalog. Preview images are rendered by the toolkit, not recreated in HTML. They do not demonstrate native input or desktop blur.

Navigation, your layout

01 / 02

All three previews share controlled app state. These are independent components, not a mandatory application shell.

How to use Rust source
Rust declarationSource
navigation([
    navigation_item(Page::Inbox, "Inbox").key("inbox").section("Mail").badge("3"),
    navigation_item(Page::Sent, "Sent").key("sent").section("Mail"),
]).key("navigation").selected(app.page)
  .placement(NavigationPlacement::Sidebar)
  .on_select(|app: &mut App, page| app.page = page)
// Use Rail or Bottom; compose independently with ordinary stacks/panels.

Catalog excerpt: names such as app, callbacks and helper functions belong to the example. View the complete source or start with the runnable app guide.

Split view

02 / 02

The Catalog's own shell: a sidebar beside the page under a draggable toolbar. Below Lg the sidebar moves into a drawer opened from the toolbar.

How to use Rust source
Rust declarationSource
navigation_split_view(
    |place| navigation(items).key(place.key("nav")).selected(app.page)
        .on_select(|app: &mut App, page| app.page = page),
    page_view(app),
)
.key("shell")
.title("Workspace")
.sidebar_header(brand)
.toolbar(toolbar)
.drawer_open(app.nav_open)
.on_drawer_change(|app: &mut App, open| app.nav_open = open)

Catalog excerpt: names such as app, callbacks and helper functions belong to the example. View the complete source or start with the runnable app guide.

Try it in the native Catalog

From the repository root. Static snapshots cannot demonstrate editing, keyboard focus, scrolling or animation.

TerminalSource
cargo run --release --locked \
    --features native-gpu,native-desktop \
    --example catalog -- --page navigation

API reference

Properties and behavior documented by this Catalog page.

APIBehavior
navigation(items)Controlled, typed destinations
.placement(Sidebar | Rail | Bottom)Vertical or horizontal destination layout
.selected(value).on_select(callback)Application owns routing and state
.selected(None)Highlight nothing, e.g. while a filter hides the current page
navigation_item(..).section(title).badge(label)Sidebar headings for consecutive items; a trailing badge such as "New"
.key(...)Stable group and item identities are required
navigation_split_view(|place| sidebar, detail)The app shell: sidebar beside a detail with a toolbar; build the sidebar's keys with place.key(..)
.drawer_open(..).on_drawer_change(..)Below Lg (or .collapse_below) the sidebar moves into a drawer
.on_sidebar_resize(..) / .material(true)A draggable divider; a frosted sidebar with a floating sheet
