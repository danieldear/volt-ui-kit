Icons

A built-in, theme-aware vector icon set.
Your state. Rust callbacks.

The previews below run the original Catalog declarations and Rust callbacks in WebAssembly. Native-only OS services are identified explicitly; this is not a simulation of desktop permissions or blur.

Your own SVG icons

02 / 03

Load any icon set or drawing. Icons follow the theme colour; multi-colour art can keep its colours.

How to use Rust source
Rust declarationSource
let star = SvgIcon::parse(include_str!("star.svg"))?;
svg_icon(&star).size(24.).color(ColorToken::Primary)

// A whole icon-set folder, by file name:
let (lucide, _skipped) = IconSet::from_dir("assets/lucide")?;
lucide.icon("arrow-left").unwrap().size(16.)

Try it in the native Catalog

From the repository root. The browser previews cover shared components; run the native Catalog for OS integrations and native platform acceptance.

TerminalSource
cargo run --release --locked \
    --features native-gpu,native-desktop \
    --example catalog -- --page icons

API reference

Properties and behavior documented by this Catalog page.

APIBehavior
icon(Icon::…)A vector glyph element (default 20 px).
.size(px) / .color(c) / .stroke(w)Scale, colour and line weight.
.accessible_label(text)Announce a meaningful icon.
ALL_ICONSEvery glyph, for galleries and pickers.
SvgIcon::parse(markup) / ::load(path)Any SVG icon or drawing.
svg_icon(&svg).size / .color / .stroke / .keep_colors(true)
IconSet::from_dir(path)A folder of .svg files, by name: set.icon("arrow-left").
