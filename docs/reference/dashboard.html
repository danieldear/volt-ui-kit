Dashboard

A dense analytics screen: KPIs, candlesticks, donut, stacked charts and orders.
Your state. Rust callbacks.

The previews below run the original Catalog declarations and Rust callbacks in WebAssembly. Native-only OS services are identified explicitly; this is not a simulation of desktop permissions or blur.

Analytics dashboard

01 / 01

A dense, data-heavy screen built only from Volt components: stats, sparklines, candlesticks with volume, donut, stacked area and bars, and a sortable table.

How to use Rust source
Rust declarationSource
candlestick_chart(candles).size(560., 250.).x_labels(dates).volume(true)
donut_chart([("Search", 4210.), ("Direct", 2980.)]).center("10.5k", "visits")
area_chart([("Pro", pro), ("Team", team)]).stacked(true).x_labels(months)
stacked_bar_chart(["Q1", "Q2"], [("Americas", vec![420., 510.])])

Catalog excerpt: names such as app, callbacks and helper functions belong to the example. View the complete source or start with the runnable app guide.

Try it in the native Catalog

From the repository root. The browser previews cover shared components; run the native Catalog for OS integrations and native platform acceptance.

TerminalSource
cargo run --release --locked \
    --features native-gpu,native-desktop \
    --example catalog -- --page dashboard

API reference

Properties and behavior documented by this Catalog page.

APIBehavior

candlestick_chart(candles)Candle::new(o, h, l, c).volume(v); .volume(true) for a strip
donut_chart(slices).center(value, caption) / .thickness / .legend
stacked_bar_chart(categories, series)Series stacked per category, with legend
nice_ticks(lo, hi, n) / short_number(v)Axis helpers: round ticks, 1.2k-style labels
