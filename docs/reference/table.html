Table

Rows and columns with sorting and selection.
Your state. Rust callbacks.

The previews below run the original Catalog declarations and Rust callbacks in WebAssembly. Native-only OS services are identified explicitly; this is not a simulation of desktop permissions or blur.

Rounded table

01 / 02

12px outer corners. Sort a header or select a row; the frame stays intact.

How to use Rust source
Rust declarationSource
//! Rounded table: 12px outer corners by default. Sort by a header or select
//! a row; the frame stays intact.
use volt_ui_kit::native::Application;
use volt_ui_kit::ui::prelude::*;

/// Invoice, status, payment method, amount.
const INVOICES: [[&str; 4]; 6] = [
    ["INV001", "Paid", "Credit card", "$250.00"],
    ["INV002", "Pending", "PayPal", "$150.00"],
    ["INV003", "Unpaid", "Bank transfer", "$350.00"],
    ["INV004", "Paid", "Credit card", "$450.00"],
    ["INV005", "Paid", "PayPal", "$550.00"],
    ["INV006", "Pending", "Bank transfer", "$200.00"],
];

#[derive(Default)]
pub struct App {
    /// The selected row: its index into `INVOICES`.
    pub row: Option<u32>,
    /// The sorted column and direction, once a header is clicked.
    pub sort: Option<(u8, SortDirection)>,
}

pub fn view(app: &App) -> Element<App> {
    let columns = [
        table_column(0u8, "Invoice").width(130.),
        table_column(1, "Status").width(120.),
        table_column(2, "Method").width(160.).sortable(false),
        table_column(3, "Amount").width(110.).align(Align::End),
    ];
    let rows = INVOICES
        .iter()
        .enumerate()
        .map(|(i, cells)| table_row(i as u32, *cells).key(format!("inv-{i}")));
    let mut invoices = table(columns, rows)
        .key("invoices")
        .width(600.)
        .rounded(12.)
        .accessible_label("Invoices")
        .selected(app.row)
        .on_select(|app: &mut App, row| app.row = Some(row))
        .on_sort(|app: &mut App, column, direction| app.sort = Some((column, direction)));
    if let Some((column, direction)) = app.sort {
        invoices = invoices.sort(column, direction);
    }
    let status = match app.row {
        Some(row) => format!("{} invoices · {} selected", INVOICES.len(), INVOICES[row as usize][0]),
        None => format!("{} invoices", INVOICES.len()),
    };
    vstack![
        invoices,
        text(status).font_size(12.).color(ColorToken::Muted),
    ]
    .gap(12., Axis::Vertical)
    .into()
}

pub fn main() -> Result<(), Box<dyn std::error::Error>> {
    Application::new("Invoices", App::default(), view)
        .size(680, 420)
        .run()
}

Square table

The same working component with 0px corners, not a static mockup.

//! selection and scrolling behave exactly as they do with rounded corners.

    ["INV004", "Paid", "Credit card", "$450.00"],

    ["INV006", "Pending", "Bank transfer", "$200.00"],

Try it in the native Catalog

From the repository root. The browser previews cover shared components; run the native Catalog for OS integrations and native platform acceptance.

TerminalSource
cargo run --release --locked \
    --features native-gpu,native-desktop \
    --example catalog -- --page table

API reference

Properties and behavior documented by this Catalog page.

APIBehavior
.rounded(12.) / .rounded(0.)Rounded by default; explicit square corners retain the same sorting, selection and scrolling.
table(columns, rows)Up to 8 columns and 96 rows; requires .key(...).
table_column(value, label).width(px)Minimum width; wider tables grow columns proportionally. Sortable unless .sortable(false).
table_row(value, cells).key(id)A typed row.
table_column(...).align(Align::Start | Center | End)Align header and values together; End for amounts.
.width(px).height(px)Bounded viewports scroll on either axis rather than cut off columns.
.sort(column, direction) / .sort_by(compare)Sorted view; custom ordering.
.selected(value) / .on_select(f) / .on_sort(f)Controlled selection and sorting.
