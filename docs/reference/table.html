Table

Rows and columns with sorting and selection.
Your state. Rust callbacks.

The examples below come from the native Catalog. Preview images are rendered by the toolkit, not recreated in HTML. They do not demonstrate native input or desktop blur.

Rounded table

01 / 02

12px outer corners. Sort a header or select a row; the frame stays intact.

How to use Rust source
Rust declarationSource
table(columns, rows)
.key("invoices")
.rounded(12.) // default outer corners
.selected(app.row)
.on_select(|app: &mut App, row| app.row = Some(row))
.on_sort(|app: &mut App, column, direction| app.sort = Some((column, direction)))

Catalog excerpt: names such as app, callbacks and helper functions belong to the example. View the complete source or start with the runnable app guide.

Square table

02 / 02

The same working component with 0px corners, not a static mockup.

How to use Rust source
Rust declarationSource
table(columns, rows)
.key("invoices-square")
.rounded(0.) // square outer frame and inset rows
.selected(app.row)
.on_select(|app: &mut App, row| app.row = Some(row))
.on_sort(|app: &mut App, column, direction| app.sort = Some((column, direction)))

Try it in the native Catalog

From the repository root. Static snapshots cannot demonstrate editing, keyboard focus, scrolling or animation.

TerminalSource
cargo run --release --locked \
    --features native-gpu,native-desktop \
    --example catalog -- --page table

API reference

Properties and behavior documented by this Catalog page.

APIBehavior
.rounded(12.) / .rounded(0.)Rounded by default; explicit square corners retain the same sorting, selection and scrolling.
table(columns, rows)Up to 8 columns and 96 rows; requires .key(...).
table_column(value, label).width(px)Minimum width; wider tables grow columns proportionally. Sortable unless .sortable(false).
table_row(value, cells).key(id)A typed row.
table_column(...).align(Align::Start | Center | End)Align header and values together; End for amounts.
.width(px).height(px)Bounded viewports scroll on either axis rather than cut off columns.
.sort(column, direction) / .sort_by(compare)Sorted view; custom ordering.
.selected(value) / .on_select(f) / .on_sort(f)Controlled selection and sorting.
