Motion studio

Carousels, sheets, card reveals, pointer reactions and viewport entrances.
Your state. Rust callbacks.

The previews below run the original Catalog declarations and Rust callbacks in WebAssembly. Native-only OS services are identified explicitly; this is not a simulation of desktop permissions or blur.

A carousel with real page motion

01 / 06

Retained pages travel by the resolved viewport width. Buttons, focus and hit targets follow the same pose; no autoplay timer.

How to use Rust source
Rust declarationSource
carousel(slides, app.slide).key("journey").height(240.)
    .slide_animation(Animation::ease_out().duration_ms(380))
    .controls_below(true).on_change(|app, i| app.slide = i)

Reveal what matters

02 / 06

The card changes size with keyed layout motion. Details slide in and out; removed content cannot receive input.

Bottom sheets, not another window

03 / 06

A real modal: focus containment, Escape, backdrop dismissal and a scrollable body reuse the drawer contract.

How to use Rust source
Rust declarationSource
bottom_sheet(order_form()).key("checkout").title("Review your order")
    .size(340.).open(app.checkout_open)
    .on_dismiss(|app| app.checkout_open = false)

Quick actions within reach

04 / 06

A controlled, non-modal speed dial. Touch-sized buttons, staggered entrances, explicit close and Escape; no hidden side effects.

How to use Rust source
Rust declarationSource
speed_dial("quick actions", [(Action::Note, "New note"), (Action::Pin, "Add waypoint")])
    .key("quick-actions").open(app.quick_open)
    .on_open_change(|app, open| app.quick_open = open)
    .on_action(|app, action| app.perform(action))

Follow, without replacing the cursor

05 / 06

A spotlight, spring-like following ring and restrained 2D card response. Touch/drag works too; wheel input still scrolls the page.

How to use Rust source
Rust declarationSource
surface.wheel_passthrough(true).on_pointer(|app, p| match p.phase {
    PointerPhase::Hover | PointerPhase::Press | PointerPhase::Drag => app.pointer = p.at,
    _ => {},
});
// Move retained children using Transform2D + Animation; do not replace the OS cursor.

Reveals that follow your reading

06 / 06

One entrance per key/revision when a box first becomes visible. Offscreen items do not run an animation timer. Reduced motion shows content immediately.

How to use Rust source
Rust declarationSource
section.key("story-step").reveal_on_scroll(Transition::slide(0., 24.).duration_ms(420))
    .transition_revision(app.replay_revision);
// Normal scrolling stays in control; this is not scroll snapping or scroll hijacking.

Try it in the native Catalog

From the repository root. The browser previews cover shared components; run the native Catalog for OS integrations and native platform acceptance.

TerminalSource
cargo run --release --locked \
    --features native-gpu,native-desktop \
    --example catalog -- --page motion-studio

Properties and behavior documented by this Catalog page.

APIBehavior

bottom_sheet(body) / speed_dial(label, actions)Controlled modal and non-modal touch-sized actions
.reveal_on_scroll(transition)One entry reveal per key/revision; never drives the scroll position
.on_pointer(...) / .wheel_passthrough(true)Pointer reactions without swallowing wheel scrolling
