Select

Choose one option from a dropdown list.
Your state. Rust callbacks.

The previews below run the original Catalog declarations and Rust callbacks in WebAssembly. Native-only OS services are identified explicitly; this is not a simulation of desktop permissions or blur.

Select

01 / 03

Escape or a click outside closes it; arrow keys move through options.

How to use Rust source
Rust declarationSource
//! Select: choose one option from a short list. Escape or a click outside
//! closes it; arrow keys move through the options.
use volt_ui_kit::native::Application;
use volt_ui_kit::ui::prelude::*;

const FRUITS: [&str; 5] = ["Apple", "Banana", "Blueberry", "Grapes", "Pineapple"];

#[derive(Default)]
pub struct App {
    /// Index into `FRUITS`.
    pub fruit: u8,
    /// The select is controlled: your state decides whether it is open.
    pub open: bool,
}

pub fn view(app: &App) -> Element<App> {
    let items = FRUITS
        .iter()
        .enumerate()
        .map(|(i, name)| select_item(i as u8, *name));
    vstack![
        text("Fruit").font_size(14.).font_weight(500),
        select(items)
            .key("fruit")
            .selected(app.fruit)
            .open(app.open)
            .width(220.)
            .on_select(|app: &mut App, fruit| app.fruit = fruit)
            .on_open_change(|app: &mut App, open| app.open = open),
        text(format!("You chose {}.", FRUITS[app.fruit as usize]))
            .font_size(13.)
            .color(ColorToken::Muted),
    ]
    .gap(8., Axis::Vertical)
    .into()
}

pub fn main() -> Result<(), Box<dyn std::error::Error>> {
    Application::new("Select", App::default(), view)
        .size(420, 360)
        .run()
}

Disabled options

02 / 03

Disabled options are skipped by keyboard and pointer.

How to use Rust source
Rust declarationSource
//! Disabled options: shown in the list, but skipped by keyboard and pointer.
use volt_ui_kit::native::Application;
use volt_ui_kit::ui::prelude::*;

const ZONES: [&str; 6] = [
    "Pacific (UTC−8)",
    "Mountain (UTC−7)",
    "Central (UTC−6)",
    "Eastern (UTC−5)",
    "London (UTC+0)",
    "Tokyo (UTC+9)",
];
/// Mountain time can't be chosen in this example.
const UNAVAILABLE: u8 = 1;

#[derive(Default)]
pub struct App {
    /// Index into `ZONES`.
    pub zone: u8,
    pub open: bool,
}

pub fn view(app: &App) -> Element<App> {
    let items = ZONES.iter().enumerate().map(|(i, name)| {
        let i = i as u8;
        select_item(i, *name).enabled(i != UNAVAILABLE)
    });
    vstack![
        text("Time zone").font_size(14.).font_weight(500),
        select(items)
            .key("zone")
            .selected(app.zone)
            .open(app.open)
            .width(260.)
            .on_select(|app: &mut App, zone| app.zone = zone)
            .on_open_change(|app: &mut App, open| app.open = open),
        text("Mountain (UTC−7) is unavailable.")
            .font_size(13.)
            .color(ColorToken::Muted),
    ]
    .gap(8., Axis::Vertical)
    .into()
}

pub fn main() -> Result<(), Box<dyn std::error::Error>> {
    Application::new("Disabled options", App::default(), view)
        .size(420, 400)
        .run()
}

Select or combobox?

03 / 03

Same field look, different jobs. Select: a short fixed list, picked by click or arrow keys. Combobox: a long list you search by typing.

How to use Rust source
Rust declarationSource
//! Select or combobox? Same field look, different jobs. A select suits a
//! short, fixed list picked by click or arrow keys; a combobox suits a long
//! list you search by typing.
use volt_ui_kit::native::Application;
use volt_ui_kit::ui::prelude::*;

const SIZES: [&str; 4] = ["Small", "Medium", "Large", "Extra large"];
const COUNTRIES: [&str; 28] = [
    "Argentina", "Australia", "Austria", "Belgium", "Brazil", "Canada", "Chile",
    "Denmark", "Finland", "France", "Germany", "India", "Ireland", "Italy", "Japan",
    "Kenya", "Mexico", "Netherlands", "New Zealand", "Norway", "Portugal",
    "Singapore", "South Korea", "Spain", "Sweden", "Switzerland", "United Kingdom",
    "United States",
];

#[derive(Default)]
pub struct App {
    /// Index into `SIZES`.
    pub size: u8,
    pub size_open: bool,
    /// Index into `COUNTRIES`, once one is chosen.
    pub country: Option<u8>,
    /// The combobox keeps its typed query and open state here.
    pub country_search: ComboboxState,
}

pub fn view(app: &App) -> Element<App> {
    let sizes = SIZES
        .iter()
        .enumerate()
        .map(|(i, name)| select_item(i as u8, *name));
    let countries = COUNTRIES
        .iter()
        .enumerate()
        .map(|(i, name)| (i as u8, *name));
    hstack![
        vstack![
            text("Select: 4 sizes").font_size(13.).color(ColorToken::Muted),
            select(sizes)
                .key("size")
                .selected(app.size)
                .open(app.size_open)
                .width(220.)
                .on_select(|app: &mut App, size| app.size = size)
                .on_open_change(|app: &mut App, open| app.size_open = open),
        ]
        .gap(6., Axis::Vertical),
        vstack![
            text("Combobox: 28 countries")
                .font_size(13.)
                .color(ColorToken::Muted),
            combobox(countries, &app.country_search)
                .key("country")
                .selected(app.country)
                .placeholder("Search countries…")
                .width(240.)
                .state(|app: &mut App| &mut app.country_search)
                .on_select(|app: &mut App, country| app.country = Some(country)),
        ]
        .gap(6., Axis::Vertical),
    ]
    .gap(40., Axis::Horizontal)
    .into()
}

pub fn main() -> Result<(), Box<dyn std::error::Error>> {
    Application::new("Select or combobox", App::default(), view)
        .size(640, 420)
        .run()
}
