Form inputs

Radio groups, steppers, comboboxes, tags, ranges, colours, codes, ratings and drops.
Your state. Rust callbacks.

The examples below come from the native Catalog. Preview images are rendered by the toolkit, not recreated in HTML. They do not demonstrate native input or desktop blur.

Radio group

01 / 10

Mutually exclusive options with optional descriptions.

How to use Rust source
Rust declarationSource
radio_group([(0, "Hobby"), (1, "Pro"), (2, "Team")])
    .key("plan")
    .selected(app.plan)
    .on_select(|app: &mut App, p| app.plan = p)

Catalog excerpt: names such as app, callbacks and helper functions belong to the example. View the complete source or start with the runnable app guide.

Number input

02 / 10

Steppers clamp to the range; typed values are parsed and rounded.

How to use Rust source
Rust declarationSource
number_input(app.weight).range(0., 20.).step(0.5).decimals(1).suffix(" kg")

Catalog excerpt: names such as app, callbacks and helper functions belong to the example. View the complete source or start with the runnable app guide.

Combobox

Type to filter, click or press Enter to choose.

Rust declarationSource

    .key("framework")
    .selected(app.framework)
    .state(|app: &mut App| &mut app.combo)
    .on_select(|app: &mut App, v| app.framework = Some(v))

Tag input

    .state(|app: &mut App| &mut app.draft)
