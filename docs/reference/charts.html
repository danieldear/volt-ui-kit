Charts

Sparklines, bar charts and line charts drawn with vector paths.
Your state. Rust callbacks.

The examples below come from the native Catalog. Preview images are rendered by the toolkit, not recreated in HTML. They do not demonstrate native input or desktop blur.

Interactive charts

01 / 04

Give a chart a key for value tooltips on hover or focus; add selected/on_select for clicks. Area, candlestick, donut and stacked-bar charts all work this way.

How to use Rust source
Rust declarationSource
stacked_bar_chart(["Q1", "Q2", "Q3", "Q4"], series)
    .key("revenue")                 // tooltips + focusable points
    .selected(app.quarter)
    .on_select(|app: &mut App, i| app.quarter = Some(i))

Catalog excerpt: names such as app, callbacks and helper functions belong to the example. View the complete source or start with the runnable app guide.

API reference

Properties and behavior documented by this Catalog page.

APIBehavior
sparkline(values, w, h)Trend line with a soft fill.
bar_chart(bars, w, h)(label, value) pairs; negative values hang below zero.
line_chart(series, w, h)(name, values) series in theme colours.
.key(k) / .selected(i) / .on_select(f)Area, candlestick, donut, stacked bars: tooltips, keyboard and click selection.
