Charts

Sparklines, bar charts and line charts drawn with vector paths.
Your state. Rust callbacks.

The previews below run the original Catalog declarations and Rust callbacks in WebAssembly. Native-only OS services are identified explicitly; this is not a simulation of desktop permissions or blur.

Line plot

01 / 09

Built for real readings: a missing value leaves a gap instead of dropping to zero, dashed guides mark reference values, and lines can glow over a soft area. It draws in once per data revision (not on every visit), and .readout(true) writes the tapped point above the plot, for touch screens where tooltips don't show.

How to use Rust source
Rust declarationSource
line_plot([("Resting", resting), ("Asleep", asleep)])   // NaN = no reading
    .key("heart").x_labels(weeks)
    .guide(55., "55 bpm").area(true).glow(true)
    .animate(app.data_revision)       // draws in once per revision
    .readout(true)                    // tap to read, on touch screens too
    .selected(app.week)
    .on_select(|app: &mut App, i| app.week = Some(i))

Catalog excerpt: names such as app, callbacks and helper functions belong to the example. View the complete source or start with the runnable app guide.

Range chart

02 / 09

Lowest to highest per column, with a dot for the middle value: daily blood pressure, temperature or prices without open and close. Ranges grow from their middle as they draw in.

How to use Rust source
Rust declarationSource
range_chart(days.iter().map(|d| ValueRange::new(d.low, d.high).mid(d.median)))
    .key("pressure").x_labels(labels).readout(true).animate(app.revision)

Timeline

03 / 09

States over time, one lane each, joined where one follows another: sleep stages, a device's modes, a pipeline's steps. Times are in your own units; value_format says how they read.

How to use Rust source
Rust declarationSource
timeline_chart(
    [("Awake", "#F59E0B"), ("REM", "#A5B4FC"), ("Light", "#818CF8"), ("Deep", "#4F46E5")],
    spans,                            // (lane, start, end)
)
.domain(0., 480.).x_labels(["23:00", "01:00", "03:00", "05:00", "07:00"])
.value_format(clock).readout(true).animate(app.revision)

Catalog excerpt: names such as app, callbacks and helper functions belong to the example. View the complete source or start with the runnable app guide.

Drawing your own

04 / 09

The canvas the plots are drawn on: arcs and ring slices (0° at 12 o'clock, clockwise), round caps and dashes, gradient fills and strokes, glows, and frames that play once per revision.

How to use Rust source
Rust declarationSource
c.stroke_with(VectorPath::arc(70., 70., 52., -120., 240.), ColorToken::Border,
    StrokeStyle::new(12.).round());
c.stroke_gradient(VectorPath::arc(70., 70., 52., -120., 240. * t),
    Gradient::linear(90., [(0., "#22D3EE"), (1., "#A78BFA")]), StrokeStyle::new(12.).round());
c.fill(VectorPath::sector(60., 70., 36., 20., 0., 112.), "#F59E0B");
c.stroke_with(VectorPath::circle(60., 70., 46.), ColorToken::Muted,
    StrokeStyle::new(2.).round().dash([0., 7.]));          // dots
c.glow_stroke(wave, "#4C9BFF", StrokeStyle::new(2.5).round(), 1.);
c.fill_gradient(VectorPath::rounded_rectangle(270., 30., 90., 80., 16.), gradient);
canvas_frames_once(frames, 24, app.revision)            // a draw-in per revision

Interactive charts

06 / 09

Give a chart a key for value tooltips on hover or focus; add selected/on_select for clicks. Area, candlestick, donut and stacked-bar charts all work this way.

How to use Rust source
Rust declarationSource
stacked_bar_chart(["Q1", "Q2", "Q3", "Q4"], series)
    .key("revenue")                 // tooltips + focusable points
    .selected(app.quarter)
    .on_select(|app: &mut App, i| app.quarter = Some(i))

Try it in the native Catalog

From the repository root. The browser previews cover shared components; run the native Catalog for OS integrations and native platform acceptance.

TerminalSource
cargo run --release --locked \
    --features native-gpu,native-desktop \
    --example catalog -- --page charts

API reference

Properties and behavior documented by this Catalog page.

APIBehavior
sparkline(values, w, h)Trend line with a soft fill.
bar_chart(bars, w, h)(label, value) pairs; negative values hang below zero.
line_chart(series, w, h)(name, values) series in theme colours.
.key(k) / .selected(i) / .on_select(f)Area, candlestick, donut, stacked bars, line plots, ranges and timelines: tooltips, keyboard and click selection.
line_plot(series)Gaps for NaN, .guide(v, label), .area, .glow, .points, .range, .colors, .readout, .animate(revision).
range_chart(columns)ValueRange::new(low, high).mid(m) per column; .color, .range, .readout, .animate.
timeline_chart(lanes, spans)(name, colour) lanes and (lane, start, end) spans; .domain, .connectors, .value_format, .readout, .animate.
VectorPath::arc / sector / rounded_rectangle / trimmedClockwise arcs and ring slices, capsules, and partial paths for draw-ins.
Canvas::stroke_with / fill_gradient / stroke_gradient / glow_strokeStrokeStyle caps, joins and dashes; gradient paint over the path's bounds; soft halos.
canvas_frames_once(frames, ms, revision)A frame sequence that plays once per revision and key, not on every visit.
