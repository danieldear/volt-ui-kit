Tabs

Switch between views; only the active page is mounted.
Your state. Rust callbacks.

The examples below come from the native Catalog. Preview images are rendered by the toolkit, not recreated in HTML. They do not demonstrate native input or desktop blur.

Tabs

01 / 02

Content for inactive tabs is never built.

How to use Rust source
Rust declarationSource
tabs([
    tab(0, "Account", account_page(app)),
    tab(1, "Password", password_page(app)),
    tab(2, "Billing", billing_page(app)).enabled(false),
])
.selected(app.tab)
.on_select(|app: &mut App, t| app.tab = t)

Try it in the native Catalog

From the repository root. Static snapshots cannot demonstrate editing, keyboard focus, scrolling or animation.

TerminalSource
cargo run --release --locked \
    --features native-gpu,native-desktop \
    --example catalog -- --page tabs

API reference

Properties and behavior documented by this Catalog page.

APIBehavior
tabs([tab(value, label, content), ...])A tab strip and the active content.
.variant(TabVariant::Contained)A raised chip in a track instead of an underline.
.placement(TabPlacement::Bottom)Put the strip below the content.
tab_bar([tab_item(...)])The strip alone, for custom content.
