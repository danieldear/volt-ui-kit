Scroll area

Opt-in vertical, horizontal or nested scrolling.
Your state. Rust callbacks.

The examples below come from the native Catalog. Preview images are rendered by the toolkit, not recreated in HTML. They do not demonstrate native input or desktop blur.

Vertical

01 / 03

Wheel, trackpad and draggable scrollbars.

How to use Rust source

Follow the newest event

03 / 03

A bounded live log. Scroll up to read history; return to the end to follow new events. The multiline composer uses Rust submission callbacks.

How to use Rust source
Rust declarationSource
vstack(lines).scroll(Scroll::Vertical).anchor_end(true)
text_area(&app.draft).submit_on_enter(true)
    .on_change(|app: &mut App, value| app.draft = value)
    .on_submit(App::append_log)

Try it in the native Catalog

From the repository root. Static snapshots cannot demonstrate editing, keyboard focus, scrolling or animation.

TerminalSource
cargo run --release --locked \
    --features native-gpu,native-desktop \
    --example catalog -- --page scroll-area

API reference

Properties and behavior documented by this Catalog page.

APIBehavior
.scroll(Scroll::Vertical | Horizontal | Both | Auto)Opt-in overflow scrolling.
.anchor_end(true)Follow growth only while the reader is at the end; scroll up to release.
text_area(...).submit_on_enter(true)Enter submits; Shift+Enter inserts a newline; Cmd/Ctrl+Enter still submits.
.scrollbars(Scrollbars::Hidden)Hide indicators, keep scrolling.
