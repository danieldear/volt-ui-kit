Toast

A brief notification that confirms an action.
Your state. Rust callbacks.

The previews below run the original Catalog declarations and Rust callbacks in WebAssembly. Native-only OS services are identified explicitly; this is not a simulation of desktop permissions or blur.

Toast

01 / 01

These buttons use the catalog's own toaster: a non-modal stack in the corner; the page stays usable.

How to use Rust source
Rust declarationSource
zstack![
    page,
    toaster(&app.toasts)
        .on_dismiss(|app: &mut App, id| app.toasts.retain(|t| t.id != id)),
]
// elsewhere:
app.toasts.push(Toast::new(id, "Changes saved").tone(Severity::Success));

Catalog excerpt: names such as app, callbacks and helper functions belong to the example. View the complete source or start with the runnable app guide.

Try it in the native Catalog

From the repository root. The browser previews cover shared components; run the native Catalog for OS integrations and native platform acceptance.

TerminalSource
cargo run --release --locked \
    --features native-gpu,native-desktop \
    --example catalog -- --page toast

API reference

Properties and behavior documented by this Catalog page.

APIBehavior
toaster(&toasts)A corner stack; layer it last in a zstack.
Toast::new(id, title).description / .tone(Severity::…) / .action(label)
.position(ToastPosition::…)Top or bottom; left, centre or right.
.on_dismiss / .on_actionRemove the toast or run its action.
TimingRemove toasts from a worker via UiSender for auto-dismiss.
