Button

Triggers an action. Six variants, three sizes and a disclosure style.
Your state. Rust callbacks.

The examples below come from the native Catalog. Preview images are rendered by the toolkit, not recreated in HTML. They do not demonstrate native input or desktop blur.

Variants

01 / 03

Emphasis presets built from theme tokens.

How to use Rust source
Rust declarationSource
button("Primary").variant(ButtonVariant::Primary).on_click(save)
button("Soft").variant(ButtonVariant::Soft)
button("Outline").variant(ButtonVariant::Outline)
button("Ghost").variant(ButtonVariant::Ghost)
button("Delete").variant(ButtonVariant::Danger)

Catalog excerpt: names such as app, callbacks and helper functions belong to the example. View the complete source or start with the runnable app guide.

Sizes

02 / 03

28, 36 and 44 pixels tall with matching type.

How to use Rust source
Rust declarationSource

button("Large").size(ControlSize::Large)

Catalog excerpt: names such as app, callbacks and helper functions belong to the example. View the complete source or start with the runnable app guide.

States

03 / 03

Disabled, toggled with animation, disclosure and label alignment.

How to use Rust source
Rust declarationSource
button(if app.liked { "Liked" } else { "Like" })
    .variant(if app.liked { ButtonVariant::Primary } else { ButtonVariant::Outline })
    .animation(Animation::ease_out().duration_ms(180))
    .on_click(|app: &mut App| app.liked = !app.liked)
button("Sort by date").disclosure(false)

Catalog excerpt: names such as app, callbacks and helper functions belong to the example. View the complete source or start with the runnable app guide.

Try it in the native Catalog

From the repository root. Static snapshots cannot demonstrate editing, keyboard focus, scrolling or animation.

TerminalSource
cargo run --release --locked \
    --features native-gpu,native-desktop \
    --example catalog -- --page button

API reference

Properties and behavior documented by this Catalog page.

APIBehavior
button(label)A clickable control; needs .on_click(...).
.variant(ButtonVariant)Neutral, Primary, Soft, Outline, Ghost or Danger.
.size(ControlSize)Small, Medium or Large.
.disclosure(open)Trailing chevron for menus and popups.
.label_align(Align)Start, centre or end.
.enabled(bool)Disable interaction and dim the button.
.key(id)Stable identity for focus, animation and tests.
