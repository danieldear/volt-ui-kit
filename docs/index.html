02 — From template to app

From an empty folder to a desktop app.

The cargo volt command creates your project, rebuilds it while you work and packages the result. Install it once from a checkout of this repository.

  1. Start from a template

    cargo volt new my-app --kit-path ../volt-ui-kit --template navigation

    Five templates: minimal, navigation, mail, settings and agent. Until the crate is published, --kit-path points at your checkout.

  2. Edit while it runs

    cargo volt dev my-app

    Rebuilds on save and restarts the app. A failed build leaves the running app alone.

  3. Package it

    cargo volt bundle

    Describe the app once in Cargo.toml. On macOS this builds a signed .app, and cargo volt release notarizes it into a disk image. Linux and Windows packaging is on the roadmap.

03 — Why Volt

Everything a desktop app needs, built in.

Layout, input, text, accessibility and rendering in one Rust crate.

  • Declarative

    Rebuild your view from state on every change. Stable keys keep input state, and damage tracking limits repaint work.

  • GPU rendered

    Shapes and text drawn by Vello on Metal, Vulkan or DX12, with an automatic software fallback.

  • Accessible

    An AccessKit tree with roles, values and actions, plus keyboard navigation and reduced motion.

  • Themeable

    Semantic colour roles, light and dark palettes and translucent tokens restyle every component at once.

  • Truly native

    Real windows with menus, a tray item, file panels, notifications and system materials. All of them work on macOS today; Linux and Windows are on the roadmap.

  • Desktop and web

    The same views, state and callbacks build a native window or compile to WebAssembly. Every live app and preview on this site is built that way.

04 — Declarative

Your interface is a function of state.

Write the view once. Change state in a callback, and Volt works out what to redraw.

  • Typed callbacks receive your state mutably
  • Stable keys keep focus, scroll and animation across rebuilds
  • An optional JSON frontend, with behaviour still in Rust

06 — Status

Where it runs today.

Volt is pre-1.0 and its APIs can change. One codebase builds the desktop app and the web version; the mobile hosts are prototypes.

macOS 11+
TestedApple silicon with Metal, including menus, the tray, file panels and notifications.
Linux and Windows
Not validatedCompiles, with headless CI configured (Vulkan, X11 and Wayland; DX12). Validation is on the roadmap.
Web
ExperimentalEverything live on this site, through WebGPU or a software canvas. Browser host guide ↗
iOS and Android
PrototypeReusable Rust hosts and project templates; physical-device acceptance is still pending.
