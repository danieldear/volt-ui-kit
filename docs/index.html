02 — Why Volt

Everything a desktop app needs, built in.

Layout, input, text, accessibility and rendering in one Rust crate.

  • Declarative

    Rebuild your view from state on every change. Stable keys keep input state, and damage tracking limits repaint work.

  • GPU rendered

    Shapes and text drawn by Vello on Metal, Vulkan or DX12, with an automatic software fallback.

  • Accessible

    An AccessKit tree with roles, values and actions, plus keyboard focus for every control and reduced motion.

  • Themeable

    Semantic colour roles, light and dark palettes and translucent tokens restyle every component at once.

  • Truly native

    Unified title bars, frosted materials, menus, a tray item, file panels and notifications on macOS.

  • Fast to start

    cargo volt new scaffolds an app; cargo volt dev rebuilds and restarts it on save.

03 — Declarative

Your interface is a function of state.

Write the view once. Change state in a callback, and Volt works out what to redraw.

  • Typed callbacks receive your state mutably
  • Stable keys keep focus, scroll and animation across rebuilds
  • An optional JSON frontend, with behaviour still in Rust

06 — Status

Where it runs today.

Volt is pre-1.0 and its APIs can change. Desktop is the foundation; web and mobile hosts are experimental.

macOS 11+
PrimaryTested on Apple silicon with Metal.
Windows and Linux
Not validatedCompiles, with headless CI configured (DX12; Vulkan, X11 and Wayland).
WebAssembly
ExperimentalLive Rust components through WebGPU or software canvas. Browser host guide ↗
iOS and Android
PrototypeiOS has an experimental Rust host/template. Android host work remains separate; mobile production acceptance is pending.
