The components and callbacks are Rust—not HTML recreations. A small browser adapter provides text input and accessibility semantics. WebGPU needs HTTPS or localhost and a compatible browser/device; software rendering is available explicitly. This prototype does not provide native menus, tray, desktop blur or file-system access.

Typography uses the bundled, open-source Inter font. SF fonts are not redistributed. No data is stored or sent by the form.
