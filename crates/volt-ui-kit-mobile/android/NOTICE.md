# Third-party build launcher

`gradlew`, `gradlew.bat` and `gradle/wrapper/gradle-wrapper.jar` are the standard
Gradle 8.13 wrapper generated by Gradle. Copyright the Gradle authors, licensed
under Apache-2.0. The scripts carry their license notice; the JAR includes the
complete license at `META-INF/LICENSE`. The distribution SHA-256 is pinned in
`gradle-wrapper.properties`. These files are build tooling, not app UI code.

Upstream: [Gradle 8.13](https://github.com/gradle/gradle/tree/v8.13.0).
